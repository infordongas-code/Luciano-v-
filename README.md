# Raízes & Vozes — Site sobre Consciência Negra

Projeto web completo desenvolvido em **HTML5**, **CSS3** e **JavaScript** puro, pronto para abrir e executar no **Visual Studio Code**.

## Estrutura de Arquivos
- `index.html`: Estrutura principal com linha do tempo histórica, galeria de personalidades, quiz interativo e mural de compromissos.
- `css/style.css`: Estilos responsivos com paleta inspirada na cultura afro-brasileira.
- `js/script.js`: Filtros dinâmicos de personalidades, lógica do quiz educativo e salvamento de mensagens no `localStorage`.

## Como abrir no VS Code
1. Extraia a pasta do arquivo `.zip`.
2. Abra o **Visual Studio Code** e clique em **Arquivo > Abrir Pasta** (`File > Open Folder`).
3. Abra o arquivo `index.html` no navegador ou clique com o botão direito e escolha **Open with Live Server**.
